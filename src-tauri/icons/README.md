# Nico Karaoke app icon

The icon is the Nico Karaoke microphone mark: an off-white microphone with three lime lyric
lines on a near-black rounded square.

- `icon.svg` is the 1024px master.
- `icon-small.svg` is a simplified variant for 16–48px, with thicker strokes and no thin border.
- The PNGs are rendered with `rsvg-convert`; the `.ico` contains 16, 24, 32, 48, 64, 128, and
  256px frames from both variants.
- Generated with ImageMagick. Keep the sources in sync when the mark changes.
