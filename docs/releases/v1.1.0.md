# Nico Karaoke {{VERSION}}

Nico Karaoke now installs signed updates from its own Settings panel. This is also the first
release with installers: Linux uses an AppImage and Windows uses a per-user NSIS installer, so
the portable archives are no longer published.

## Highlights

- **In-app updates:** Settings shows the installed version and checks GitHub Releases. An
  available update adds a badge to the gear and a one-time toast; installing it always needs
  your confirmation. After this release, future versions arrive without downloading a new
  archive by hand.
- **Settings panel:** one gear on the player, the idle screen, and the Studio holds the accent
  colour. The idle colour dots moved into it; the language switch stays on the idle screen.
- **Create lyrics when the lookup finds nothing:** the Library now offers **New lyrics** and a
  card for the current track, opening an empty Studio document bound to that track.
- **Fewer duplicate records:** a credit inside a video title (`Artist - Song` or
  `Artist - Song (Official Video)`) matches the saved record, and a failed lookup retries with
  that credit. This keeps one record for the same song across YouTube and YouTube Music.
- The lookup still refuses a video whose length is far from the song, so the app never forces
  mistimed lyrics onto a different edit.

## Downloads

- **Linux x86_64:** `NicoKaraoke-{{VERSION}}-linux-x86_64.AppImage`
- **Windows x86_64:** `NicoKaraoke-{{VERSION}}-windows-x86_64-setup.exe`
- **Updater manifest:** `latest.json`
- **Checksums:** `SHA256SUMS.txt`

## Install

This is the first updater-enabled release, so install it once manually. Later releases can
update themselves.

- **Linux:** make the AppImage executable and run it:
  `chmod +x NicoKaraoke-{{VERSION}}-linux-x86_64.AppImage` and run that file. Keep it in a
  writable folder so it can replace itself during an update. The AppImage bundles WebKitGTK and
  needs FUSE 2 (`fuse2` on Arch, `libfuse2t64` on Ubuntu 24.04, `libfuse2` on older
  Debian/Ubuntu).
- **Windows:** run the setup executable. It installs per user and does not need administrator
  rights. The WebView2 runtime is required; Windows 11 includes it and most Windows 10 systems
  already have it.

The Windows installer is not code-signed, so SmartScreen may show an "Unknown publisher"
warning. The separate updater signature protects later downloads.

Verify the download with `sha256sum -c SHA256SUMS.txt` on Linux or `Get-FileHash` on Windows.

## Updating and uninstalling

- **Updates:** open **Settings → Check for updates**. A release build checks at startup and
  shows a badge and a one-time toast when a newer version is available. Development builds and
  the browser fallback never update.
- **Linux AppImage:** updates replace the AppImage file. To uninstall, delete the AppImage. The
  data folder `~/.local/share/nico-karaoke/` remains; delete it to remove saved lyrics and logs.
- **Windows:** uninstall through **Settings → Apps → Installed apps → Nico Karaoke →
  Uninstall**. The data folder remains; delete it to remove saved lyrics and logs.

## Known limitations

- Linux and Windows x86_64 only; macOS is not released.
- A `.deb`, Arch package, or package-managed install is not offered yet. Those builds would
  update through their package manager rather than the in-app updater.
- The Windows installer is not Authenticode code-signed.
