# Nico Karaoke {{VERSION}}

This release improves the lyric view on large displays, adds a red accent palette, and makes
the library easier to browse. It is also the first in-app update after 1.1.0, so it exercises
the signed updater end to end.

## Highlights

- **Larger lyrics on large screens:** the lyric size now follows both the window width and
  height. A 5120×1440 window gets 80.6 px text instead of the old 45.6 px cap, while 1440×900
  only grows slightly. The line height and fill clipping also keep descenders such as “y”
  fully coloured.
- **Red accent palette:** a sixth accent colour with matching reel-to-reel artwork on the idle
  screen.
- **Library filters and sorting:** filter on Synced, Needs timing, or My edits, and sort by last
  update, title, or artist. Both choices are remembered on this device.
- **Clearer current song:** the playing item has a **Now playing** badge and extra spacing. The
  duplicate “New lyrics” card is gone; the header button is the single action.
- **Documentation:** the README now covers installation and daily use, with developer notes in
  `docs/development.md`.

## Downloads

- **Linux x86_64:** `NicoKaraoke-{{VERSION}}-linux-x86_64.AppImage`
- **Windows x86_64:** `NicoKaraoke-{{VERSION}}-windows-x86_64-setup.exe`
- **Updater manifest:** `latest.json`
- **Checksums:** `SHA256SUMS.txt`

## Install

If you already run 1.1.0, open **Settings → Check for updates** and install this release there.
This is the first update delivered through the in-app updater; the downloaded update is signed
and installed only after confirmation.

For a new installation:

- **Linux:** make the AppImage executable and run it:
  `chmod +x NicoKaraoke-{{VERSION}}-linux-x86_64.AppImage`. Keep it in a writable folder so it
  can replace itself during an update. The AppImage bundles WebKitGTK and needs FUSE 2
  (`fuse2` on Arch, `libfuse2t64` on Ubuntu 24.04, `libfuse2` on older Debian/Ubuntu).
- **Windows:** run the setup executable. It installs per user and does not need administrator
  rights. The WebView2 runtime is required; Windows 11 includes it and most Windows 10 systems
  already have it.

The Windows installer is not code-signed, so SmartScreen may show an “Unknown publisher”
warning. The separate updater signature protects later downloads.

Verify the download with `sha256sum -c SHA256SUMS.txt` on Linux or `Get-FileHash` on Windows.

## Updating and uninstalling

- **Updates:** open **Settings → Check for updates**. A release build checks at startup and
  shows a badge and a one-time toast when a newer version is available. Installing an update
  always requires confirmation.
- **Linux AppImage:** updates replace the AppImage file. To uninstall, delete the AppImage. The
  data folder `~/.local/share/nico-karaoke/` remains; delete it to remove saved lyrics and logs.
- **Windows:** uninstall through **Settings → Apps → Installed apps → Nico Karaoke →
  Uninstall**. The data folder remains; delete it to remove saved lyrics and logs.

## Known limitations

- Linux and Windows x86_64 only; macOS is not released.
- A `.deb`, Arch package, or package-managed install is not offered yet. Those builds would
  update through their package manager rather than the in-app updater.
- The Windows installer is not Authenticode code-signed.
- The new large-display typography was measured at 5120×1440 in headless Chromium. A live
  Windows ultrawide check is still welcome and may lead to another size adjustment.
