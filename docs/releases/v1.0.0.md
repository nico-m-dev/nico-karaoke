# Nico Karaoke {{VERSION}}

The first public release: synchronised lyrics for whatever is playing in another application,
with a local library and a Studio for fixing text and timing.

## Highlights

- Live karaoke view with the active line filling as playback advances.
- MPRIS on Linux and SMTC on Windows, including play, pause, and seek where the player
  supports it.
- LRCLIB lookup, a searchable local library, and a Studio with tap mode and raw LRC editing.
- Five accent palettes with matching vintage instrument artwork.
- English and Dutch interface.
- Local-only server: no account, telemetry, analytics, or audio capture.

## Downloads

- **Linux x86_64:** `NicoKaraoke-{{VERSION}}-linux-x86_64.tar.gz`
- **Windows x86_64:** `NicoKaraoke-{{VERSION}}-windows-x86_64.zip`
- **Checksums:** `SHA256SUMS.txt`

## Requirements

- **Linux:** WebKitGTK 4.1, GTK 3, libsoup 3, and librsvg. The binary is built on Ubuntu 24.04
  and needs glibc 2.39 or newer.
- **Windows:** the WebView2 runtime. Windows 11 includes it; most Windows 10 systems already
  have it.
- An internet connection for lyric lookup. Playback stays in your own player.

## Install

Both downloads are portable archives. Extract them and run `NicoKaraoke` (Linux) or
`NicoKaraoke.exe` (Windows). There is no installer and no automatic update.

The Windows executable is not code-signed, so SmartScreen may show an "Unknown publisher"
warning.

Verify the download with `sha256sum -c SHA256SUMS.txt` on Linux or `Get-FileHash` on Windows.

## Known limitations

- Linux and Windows x86_64 only; macOS is not released.
- Portable archives, not installers.
- No automatic updates.
- Lyrics and the library stay local; the app never uploads them.
