# Nico Karaoke {{VERSION}}

This is a maintenance release with no functional changes. It updates
dependencies with security fixes and keeps the build green on current Rust.

## Security and maintenance

- `time`, `url`, and the `plist`/`quick-xml` dependency chain now use patched
  releases, found by `cargo audit`.
- CI runs both `cargo audit` and `npm audit`, with a weekly scheduled audit.
- Two advisories remain blocked upstream: `zip` (through the updater) and
  `glib` (through GTK). They are documented in `.cargo/audit.toml` and will be
  revisited when the Tauri/GTK stack updates.
- Building from source now requires Rust 1.88.

There is nothing new to try in the app itself; this release is about keeping
the dependency tree current.

## Downloads

- **Linux x86_64:** `NicoKaraoke-{{VERSION}}-linux-x86_64.AppImage`
- **Windows x86_64:** `NicoKaraoke-{{VERSION}}-windows-x86_64-setup.exe`
- **Updater manifest:** `latest.json`
- **Checksums:** `SHA256SUMS.txt`

## Install

If you already run 1.2.0, open **Settings → Check for updates** and install this
release there. The downloaded update is signed and installed only after
confirmation.

For a new installation:

- **Linux:** make the AppImage executable and run it:
  `chmod +x NicoKaraoke-{{VERSION}}-linux-x86_64.AppImage`. Keep it in a
  writable folder so it can replace itself during an update.
- **Windows:** run the setup executable and follow the installer.
